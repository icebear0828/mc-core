# 艾尔登法环 真机验证清单

用法：你完成一项就按编号汇报（贴日志或一句结论）；我核对后把 `[ ]` 改成 `[x]`，并把结果写进 `docs/ELDENRING_REVERSE.md`。
没有编号对应的数据，我不会勾。评级规则：A=实机读到或看到，B=反汇编或单次样本，C=推断。

- 类型：**R** = 只读（外部进程读内存，不注入、不写）；**I** = 需要注入或钩子；**W** = 需要写游戏内存。
- 优先级：**P0** 阻塞主功能，**P1** 影响体验，**P2** 收尾。
- 所有项只在 `eldenring.exe 2.7.1.0`、离线、无 EAC 下验证。
