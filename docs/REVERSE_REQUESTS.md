# 逆向任务清单（给逆向 agent，2026-10-09 夜；取代 REVERSE_REQUESTS_JUMP_FLY_SUMMON.md）

目标程序：`eldenring.exe` 2.7.1.0（Steam，离线，无 EAC）。我们是 `dinput8.dll` 代理加载器 + MinHook，在游戏进程内读写内存、挂钩子。

## 0. 给 agent 的规则（先读，违反的回复会被整条退回）

1. **每条结论必须带**：绝对 VA、该处的**原始机器码字节（hex）**、反汇编、调用者/被调用者。我们会逐字节核对；字节写错、地址对不上的整条不采信。
2. **证据等级**：A=实机读到（给出读到的值与场景）；B=反汇编确证（给字节）；C=推断。**C 级请明说“推断”，不要写成事实**。拿不准就写“未证实”。
3. **外部来源不算证据**：参数库、社区文档、模型记忆里的 ID/偏移一律只当线索；Param 的 ID 必须给**运行时读取方法**和读到的行内容。
4. **不要给“写某个字段就能…”的方案**：我们已试过往 `PhysicsModule+0x92/+0x1D0/+0x1D1/+0x1B8`、`FallModule+0x18` 写值，**全部**造成“走不动/爬行/镜头变慢”。要的是**可以调用的函数**、**可以跳过的决策点**、或**游戏自己的状态切换入口**。
5. **不要引用我们仓库里不存在的文件**（如 `ELDENRING_VERIFIED_EVIDENCE.md`）。要交付的代码/脚本请放进仓库让我们审查，不要只说“已通过测试”。
6. 回复格式（每条）：`结论一句话 → 证据（VA + 字节 + 反汇编）→ 等级 → 我们如何在运行时只读验证 → 已知风险`。

## 1. 我们已确认的事实（不用再查，别再推翻或重复）

- `WorldChrMan` 全局 `0x143D69FF8`；玩家 `ChrIns` = `[WorldChrMan+0x1E508]`；`CSBuddyMan` = `[WorldChrMan+0x1E538]`；`ChrIns+0x190`=模块容器（槽 0x68 物理 / 0x70 坠落 / 0xE8 …）；`ChrIns+0x58`=ChrCommonData；`ChrIns+0x6C`=teamType。
- `[[chr+0x58]+0xC8]+0x24` bit0 = **已死亡**标志（`KillChr 0x1403FCD90` 内 `0x1403FCDE1` 置位；复活 `0x1403EA2C0` 清除）。**绝不能写。**
- 摔死链：`0x14042BC12 call 0x1403F4740`（读 bit0）→`test al,al; jne 0x14042BC2A`→`0x14042BC1E call 0x1403EDA70`（击杀包装，4 个调用者 `0x1403E93DE/0x1403F8543/0x140428EEB/0x14042BC1E`）。包装在 `KillChr` 之后继续执行 `0x1403FEF40/0x1403FDFA0/0x1403FC4A0/0x1403FC680`。
- `0x14044E090`：重着陆处理，**不能当复位调用**；无 SpEffect `0x8F` 时写 `[[chr+0x190]+8]+0x34=6`；2 个调用者 `0x14045AF25/0x14045AF90`。
- `PhysModule+0x1C0`（setter `0x14045FB30`，调用点 `0x14042687E/0x140428780/0x14042879D`）不是重力。
- 召唤：请求 `man+0x20` = 骨灰ID×100+等级（群狼 232000）；石碑 `man+0x3C`（实体ID，如 1042360100）；出生点 `man+0xA0`（4 float）、朝向 `man+0xB0`；道具代码同一瞬间写入请求/石碑/出生点（= 玩家位置 + 3 m × -(sin h,0,cos h)，朝向 = 玩家 heading），下一帧由 `0x1404B89C2 call 0x1404BBDD0` 消费；生成的狼 `npc=4070 team=47 hp=500`。
- 输入走 DirectInput；相机拷贝 `0x4A7190`；实机物理：`PhysicsModule+0x70` 位置、`+0x80` 上一帧位置、`+0x120` 线速度（只读镜像，写入会被覆盖）。
- 已被证伪的见 `docs/ELDENRING_HANDOFF.md` 第 8 节与 `docs/ELDENRING_REVERSE.md` §29。

## 2. 创造模式（最高优先级：MC 起跳 + 飞行 + 免摔死）

**总思路**：对玩家**跳过决策函数**或调用**游戏自己的状态入口**，不往状态字段写值。

**C1 摔死触发全貌（P0）**
- 击杀包装 `0x1403EDA70` 的 4 个调用者各自是什么（坠落致死 / 出界 / 虚空 / 脚本 / 其它）？给每个调用点所在函数的作用。
- `0x14042BBC0~0x14042BC1E` 这段判定的**全部输入**：`xmm6/xmm7`、`[rbp-5]`、`[rbp+0xb]`、`[rbp-9]` 各是什么变量（累计高度？距离？时间？），阈值（约 20 m？）的**常量地址或 Param 来源**及实际数值。回答“怎样才算摔死”。
- 这个函数的完整入口、谁调用它、多久一次、是否只对玩家。

**C2 重着陆 `0x14044E090`（P0）**
- 两个调用者 `0x14045AF25/0x14045AF90` 各自所在函数的触发条件（什么算“落地”）。
- 跳过它之后角色会卡在什么状态？要让角色回到正常站立/奔跑，**游戏自己的哪个函数**负责（给 VA、签名、调用前提）。
- `SpEffect 0x8F`（`0x1404FA370` 查询）到底是什么效果（名称、持续、来源）？**给出“给玩家添加/移除一个 SpEffect”的游戏函数签名**（AddSpEffect/RemoveSpEffect：VA、参数、线程要求）。如果添加 0x8F 就能让重着陆不触发，那是最干净的免摔方案——请验证并给出证据。

**C3 接地判定（P0）**
- `PhysicsModule+0x92`、`+0x1D0`、`+0x1D1`、`+0x93` 的**所有写入点**（VA+字节）和语义。给出“角色底部向下探测”的函数 VA、输入输出。
- 我们每帧写位置把玩家“摆”在方块上时，引擎仍判定悬空。**除了注册 Havok 刚体之外，是否有游戏自己的“强制接地/站在某个平面上”入口**（骑乘落地、电梯、传送落地、地面吸附）？给函数。

**C4 坠落模块（P0）**
- `FallModule`（`ChrIns+0x190` 槽 0x70）完整布局：`+0x18/+0x1D/+0x1E` 及所有字段，**所有写入点**（给 VA+字节），尤其是 `+0x18` 的清零条件。上一轮回复称“`+0x92` 上升沿清零”但**没给地址**——请给。
- `0x14044E340/0x14044E3AA` 比较的阈值来源。
- 注意：我们已试过从外部写 `+0x18`，会导致走不动。请解释**为什么**（谁在读它做状态切换，在哪个函数、哪个地址）。

**C5 MC 起跳（P0）**
- 按下跳跃键 → 动作系统 → TAE 事件 `JumpTakeOff` → 给垂直初速度的**完整调用链**，每一环 VA。给出“施加起跳速度”的函数 VA、签名、速度来源（Param/常量）。
- 前摇 0.7~0.8 s 由什么决定（动画长度？状态机计时？）。是否有办法**直接调用“起跳瞬间”**或跳过前摇（调用某函数、改动画播放速度的官方入口），而不是写位置。上一轮说的 `ActionModule vfunc[18]` **无地址**，请给 VA 与字节，或承认不存在。

**C6 重力与无重力移动（飞行，P0）**
- 角色的 Havok 控制器/代理（character proxy / controller）如何积分重力；重力常数在哪；**有哪些游戏原生状态是不受重力的**（游泳、爬梯子、骑乘滑翔、某些法术/灰烬战技、调试飞行），每个对应的**进入/退出函数**与状态字段（给 VA）。
- 其中“爬梯子”和“游泳”最有价值（垂直移动、无坠落计时）：它们如何标记 `PhysicsModule`/`ChrIns` 状态，能否用函数调用进入而不是写字段。
- 上一轮回复里的 `IsFlyState`（字符串 `0x142A093D0`）只是函数名表。若真有飞行状态，请给**状态机里的对应实现地址**，不要只给字符串。

**C7 高处堆柱后“死亡流程半截”（P1）**
- 我们现有的“跳过内部 KillChr”后角色冒粒子、不能动，原因已确认是注销链 `0x1403FEF40…` 仍执行。请确认：**对玩家直接跳过整个 `0x1403EDA70`** 会不会遗漏必须的状态（比如 `0x14042BC23 mov cl,1; call 0x140258830` 是否必须执行）。给 `0x140258830(1)` 的作用。

**C8 真实方块碰撞（Havok，阶段 B，P2）**
- 在地图的 `hknpWorld` 里创建/销毁一个静态长方体刚体的**可调用路径**：函数 VA、签名、所需对象（shape 创建、body cinfo 布局、碰撞过滤器、物质/摩擦）、线程要求、如何拿到当前地图的 `hknpWorld`。上一轮的 `0x141934830 addBody` **只有函数开头，没有名字依据**——请给出能把它认定为 addBody 的证据，以及一个完整的调用示例（参数怎么填）。如判断不可行，请明说并给理由。
