  ### 一、突破口 1：解除原版“墓碑/石碑限制”（实现全地图随时刷怪）

  原版《艾尔登法环》将召唤限制在特定的“重生石碑（Sekihi）”区域内。逆向已准确定位引擎控制石碑校验的两个底层汇编关卡：

  #### 1. 石碑有效距离门限检测点（0x140EA1577）

    ; eldenring.exe (2.7.1.0)
    0x140EA1577: mov    rax, qword ptr [rdi + 0x28] ; 读取石碑/区域上下文
    0x140EA157B: movss  xmm2, dword ptr [rax + 0x84] ; 读取玩家与石碑的物理距离
    0x140EA1583: comiss xmm2, xmm0
    0x140EA1588: movaps xmm1, xmm2
    0x140EA158B: mulss  xmm1, xmm1
    0x140EA158F: comiss xmm1, dword ptr [rsi + 0x3fc] ; 比较是否在召唤石碑允许范围内
    0x140EA1596: jbe    0x140ea15de                  ; <--- 关键分支：距离超限则失败

  • Hook/补丁策略：在 0x140EA1577 处拦截，将 xmm2 强制注入极大值（例如 1000.0f）或直接将 0x140EA1596 的 jbe 改为无条件跳转 jmp 0x140ea15de，即可彻底解除距离限制。

  #### 2. 石碑激活状态与区域校验点（0x140EA58D0）

    0x140EA58D0: mov  rax, qword ptr [rbp - 0x68]
    0x140EA58D4: test rax, rax
    0x140EA58D7: je   0x140ea6124 ; 失败跳转（清空 HUD 墓碑图标，禁用召唤道具）
    0x140EA58DD: mov  eax, dword ptr [rax + 0x20]

  • Hook/补丁策略：将 [rax + 0x20] 强制置 0，word ptr [rax + 0x1C] 强制置 0xFFFF，即可无视地图区域锁，使物品栏的“刷怪蛋”全图随时亮起可用。

  ### 二、突破口 2：阵营安全隔离（teamType = 47）

  制作友军召唤物最致命的风险是“玩家一刀把自己的召唤物砍死”或“苦力怕自爆炸死玩家”。

  • 在 NpcParam 中，原版敌对怪物是 teamType = 6。
  • 逆向确证：灵灰/召唤友军的专属阵营代码是 teamType = 47（Spirit Summon 阵营）。
      • 设置为 47 后，引擎判定矩阵自动生效：免疫玩家的普通近战挥砍与弹道误伤，主动索敌锁定攻击玩家的目标，脱战后自动向玩家收拢。

  ### 四、突破口 4：移除幽灵蓝光（还原实体方块不透明材质）

  原版骨灰在通过 BuddyParam 生成时，会附带一层全屏泛蓝的半透明幽灵滤镜（Ghost Material Shader），导致所有模型看起来像“鬼魂”。

  • 参数位置：BuddyParam.dopingSpEffect 以及实体生成时附带的材质覆写 SpEffect。
  • 去幽灵化：将自定义召唤项所引用的 SpEffectParam 中关于 materialEffect / ghostEffect 的 Shader 标志位清除，召唤出的 MC 方块人即会呈现原汁原味、不透明的像素实体渲染。
