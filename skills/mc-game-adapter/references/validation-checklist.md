# 适配器验收与质量门禁清单 (Validation Checklist)

在任何游戏适配器声明“完成”之前，必须逐项进行实机验证并勾选：

---

## 1. 原生角色与视觉挂载验收 (Visual & Avatar)
- [ ] **隐身彻底性**：激活 Steve 模式时，原主角模型（皮肤、衣服、原生武器）100% 隐藏，无残留投影或重影。
- [ ] **骨骼非拉伸**：12 个方块部件保持纯硬直立方体状态，无写实关节扭曲或面条拉伸。
- [ ] **步态对称性**：玩家走跑时，双腿呈现正弦相位反向摆动，手臂呼吸起伏正常。
- [ ] **视角跟随**：第一/第三人称切换正常，转动镜头时 Steve 头部 Pitch 与 Yaw 角度精确跟随。
- [ ] **手持物绑定**：主手/副手武器与方块精确贴合手腕 Socket，无悬空或反向。

---

## 2. 物理与体素世界验收 (Physics & Voxel)
- [ ] **原生物理复用**：主角走、跑、跳、下落重力完全复用游戏原生物理胶囊体，不穿模跌出地图。
- [ ] **方块精准吸附**：对准地面/墙面 5 米内右键放置，方块严格对齐 100cm 世界栅格。
- [ ] **实体站立阻挡**：玩家自身与任意原生 NPC 均可正常踩踏在放置的方块上，不会穿模掉落。
- [ ] **防卡死检测**：当方块位置与玩家当前胶囊体交叠时，能正确拒绝放置。
- [ ] **完整挖掘周期**：手持钻石镐左键长按，表面显示裂纹递进（阶段 0 到 9），破碎后视觉与碰撞体同时移除。

---

## 3. 战斗与受击分发验收 (Combat & Ballistics)
- [ ] **原生伤害生效**：挥击钻石剑能对原生敌人造成伤害，敌人血条扣减正常。
- [ ] **暴击与击退**：下落攻击触发暴击，敌人触发原生受击动画、削韧或布娃娃（Ragdoll）击飞。
- [ ] **弹道阻力与下坠**：弓箭射出具有重力下坠抛物线，撞击世界几何时停止。
- [ ] **TNT 爆破冲量**：TNT 倒计时结束爆炸，对周围原生敌人施加物理冲击力。

---

## 4. 稳定性与生命周期验收 (Lifecycle & Stability)
- [ ] **无内存泄漏**：频繁切换 Steve 模式与退出游戏，方块和 Part 实体均被显式清理。
- [ ] **安全状态守卫**：在剧情过场（Cutscene）、乘坐载具、攀爬梯子时，状态机能正确抑制或安全挂起。

---

## 5. 真机绑定与证据验收 (Live Binding & Evidence)
- [ ] **绑定可靠**：特征码在解密后的运行映像里唯一命中；失败时日志写明状态，**没有兜底对象**。
- [ ] **单位/手性实测**：速度换算 + "向右转镜头"实验，转换有单测。
- [ ] **写内存有依据**：RTTI 类名 + setter/当前值；写前校验、记原值、可还原；无批量盲写。
- [ ] **截图证据**：F7 截图中模型比例、位置、颜色正确；暗背景下用肉眼看图，不只信差分分数。
- [ ] **资产不入库**：真实贴图只在本地生成；日志写明来源。
- [ ] **不 cast 游戏内存**：适配器只操作镜像结构。
- [ ] **干净退出**：卸载/退出模式后原角色恢复。
完整方法与踩坑见 `docs/PORTING_PLAYBOOK.md`。
